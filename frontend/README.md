# Plasma Connect Frontend

React.js frontend using Create React App, Tailwind CSS, Axios, React Router, and Leaflet (OpenStreetMap).

## Scripts
- `npm start` - run dev server
- `npm run build` - production build
- `npm test` - tests

## Environment
Create `.env` from `.env.example`:

```env
REACT_APP_API_BASE_URL=http://localhost:5000/api/v1
REACT_APP_SOCKET_URL=http://localhost:5000
FAST_REFRESH=false
```
